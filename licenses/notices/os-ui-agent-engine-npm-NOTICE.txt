Sovereign Agentic OS — os-ui agent engine npm libraries (engine rebuild, Phase A0)
==================================================================================

These Node.js libraries are dependencies of our own os-ui application code (os-ui/package.json),
installed from the npm registry and traced into the os-ui image. Each is MIT-licensed; the
per-package copyright notices below are reproduced verbatim from the LICENSE file shipped in
the npm tarball (langfuse ships none in its tarball — its text is reproduced from the upstream
repository, https://github.com/langfuse/langfuse-js/blob/main/LICENSE, same declared MIT).
The generic MIT text is licenses/MIT.txt. The LangGraph *Platform* (Elastic-licensed) is NOT a
dependency and is not bundled.
